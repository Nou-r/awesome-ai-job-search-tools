# Contributing

Thanks for helping keep this list useful. It is curated, so additions clear a bar. This file is that bar.

Maintained by [Landed](https://www.landed.jobs). landed makes an auto-apply product, and its own tools are marked "(maintainer's tool)" in the list. No affiliation with any other tool named here.

## Inclusion criteria

A tool gets in when all of these hold:

1. **It works today.** A live product or a maintained repo. No waitlists, no "coming soon", no landing page without a product behind it.
2. **It has real users.** Public reviews, an active community, or for repos roughly 100+ stars or visible recent commits.
3. **It helps job seekers directly.** Recruiter and employer tools belong elsewhere.
4. **It adds something.** It does a job the list doesn't already cover, or does it in a clearly different way (free where others are paid, self-hosted, a different region).
5. **No affiliate, referral or tracking links.** Link the tool's plain home page or the specific feature page.

We remove entries whose site goes dark, whose pricing turns deceptive, or whose repo is archived for more than a year with no replacement.

## Entry format

One line, in the right section, in this shape:

```markdown
- [Name](https://example.com) - What it does, in plain words. Pricing model. Known downside, if there is one.
```

- **Description from the tool's own site.** Don't copy marketing claims ("#1", "10x more interviews"). Say what it does.
- **Pricing:** `Free`, `Freemium` or `Paid`, with the starting price if the site shows one. If the site hides pricing, say so.
- **Downside:** say it when it is well known. Mass-apply tools tend to get low response rates. Tools that automate LinkedIn break its [User Agreement](https://www.linkedin.com/legal/user-agreement). Cheap trials that renew at a higher price.
- **Repos:** add the license and approximate stars, e.g. `MIT, about 4k stars.` Note when there is no license file.
- Start with a capital letter and end with a period. No emoji in entries.

## Writing style

- Plain and specific. No hype words ("powerful", "seamless", "revolutionary").
- Sentence-case headings.
- Straight quotes, no em dashes.

## How to contribute

1. Open an issue with a [template](.github/ISSUE_TEMPLATE/) to suggest a tool or report a problem, or go straight to a PR for a small fix.
2. Fork, branch, edit `README.md`.
3. Keep internal links relative and check they resolve. CI runs [lychee](.github/workflows/links.yml) on every PR.
4. Open a PR and fill in the [PR checklist](.github/PULL_REQUEST_TEMPLATE.md).

Stop spraying. Get **matched**, get **prepped**, get **Landed**.
